Симулятор леса, поселить в нём зайцев-беляков.  
Цвет шерсти у всех зайцев color меняется в зависимости от времени года season: зимой — белый, летом — серо-рыжий.

Так как цвет шерсти у всех зайцев одинаковый и меняется одновременно, переменная color должна быть статической.  
А остальные параметры индивидуальны для каждого зайца.

Время года одинаково для всех лесов смешанного типа, поэтому переменная season должна быть статической.  
Чтобы запретить смену времени года без изменения цвета шубок, необходимо объявить эту переменную с модификатором private.

Метод setSeason(String newSeason) должен быть статическим, так как смена времени года не зависит от леса.  
В этом методе реализуйте логику смены цвета шубок зайцев-беляков:  
если время года — "зима", то цвет зайцев — "белый", а иначе — "серо-рыжий".

Печать списка зайцев можно реализовать с помощью цикла for по списку (MountainHare hare : hares).  

Для того чтобы создать летний лес, воспользуйтесь сеттером и поменяйте сезон на "лето".
